A FEW USEFUL ANSWERS

Good to know.

Will my short links still work when I close the browser?

With a properly deployed backend and persistent database, yes. On the local H2 demo profile, data is reset when the Java server stops.

Can people use my QR code without signing in?

Yes. Only the link owner needs an account to manage or download the QR. Anyone with a working short-link address or QR code can open its destination.

What does the visit counter show?

It counts requests to each short link. It does not currently measure unique visitors or detailed device/location analytics.

Is this the same as Zrain Auth Cloud?

No. Accounts in this application belong to the Zrain Links backend. The separate Zrain Auth Cloud identity service has not been built.
